# Nuxt 3 Project

Проект на Nuxt 3 с Vue 3 и SCSS.

## Установка

```bash
npm install
```

## Разработка

Запустите сервер разработки:

```bash
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

## Сборка

Для сборки проекта:

```bash
npm run build
```

## Просмотр собранного проекта

```bash
npm run preview
```
